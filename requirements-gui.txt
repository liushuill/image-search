-r requirements.txt

PySide6>=6.6.0,<6.12
# ⚠️ 暂不放开到 6.12，但**不要把这条当成「6.12 有 bug」的结论**。
#
# 实测记录（Windows 11 + Python 3.14 + 6.12.0）：整套测试用例全过，
# 但进程在退出时以 0xC0000409 结束；换回 6.11.2 后没有复现。
#
# 后续排查发现 0xC0000409 正是 Windows 上 abort() 的返回码，而 Qt 在
# 「QThread 还在跑就被销毁」时会 qFatal() → abort。我们当时确实有这个问题
# （缩略图线程 stop() 只等 3 秒，而下载超时 8 秒），已在 2026-10 修复。
# 因此当初那次崩溃**可能根本不是 6.12 的问题**，只是概率不同。
#
# 结论：这条限制先留着（成本为零），等用 6.12 复测一轮再决定是否放开。
#    等 6.13 出来再评估。
